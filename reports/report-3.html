SEO

✗ No meta description P1
Why it matters: The description is the free ad copy under your Google listing. Missing = Google writes it, badly.
Fix: Write a 120–155 char description per key page: what, where, why call you.
✓ Canonical set
✓ Indexable
✓ robots.txt present (no sitemap line)
✗ No sitemap.xml P2
Why it matters: A sitemap gets every service page indexed instead of just the homepage.
Fix: Generate sitemap.xml (every CMS and most hosts can do this automatically) and reference it in robots.txt.

Structure

✗ 6 <h1> tags P2
Why it matters: One clear H1 tells Google and screen readers what the page is about. Zero or five dilutes it.
Fix: Use exactly one <h1> per page — the page's main headline.

Accessibility

✗ 16 images, 8 missing alt text P2
Why it matters: Alt text serves screen-reader users AND Google image search. Missing alt on a gallery-heavy site loses both.
Fix: Add descriptive alt text to content images (decorative ones get alt="").
✓ lang="en"

Social

✗ 0 Open Graph tags P2
Why it matters: Without OG tags, sharing your page on Facebook/iMessage shows a bare or broken preview — free marketing lost.
Fix: Add og:title, og:description, og:image to the homepage.
